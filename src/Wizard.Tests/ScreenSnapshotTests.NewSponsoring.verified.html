Maintenance fee

Verify participates in the Open Source Maintenance Fee. Organizations using Verify's packages in revenue-generating activities (annual revenue of US$10,000 or more) sponsor VerifyTests at the tier matching their size. Individuals, non-revenue open source projects and small organizations are exempt. Every build checks for a declaration in Directory.Build.props.

The organization or user that sponsors VerifyTests.

Expected build outcome: When the start date is after the referenced Verify version was packed, the build passes and logs an SC017 audit message. A future date fails with SC028. After upgrading to a Verify version packed later than the start date, the normal bundled-list check applies and Verify_SponsorshipStart can be removed.

Full documentation is in the Verify readme and the docs folder. Wizard source: VerifyTests/Wizard.
